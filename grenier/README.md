# Grenier — archives du projet

Ces fichiers sont conservés pour consultation. Ils ne sont ni nécessaires au
lancement d’App_vibration V1.3 ni inclus dans sa suite de tests.

- `documentation/` : notes des étapes 2 à 7, déplacées sans modification.
- L'ancienne application RF indépendante reste consultable dans l'historique
  et le tag `v1.1` ; elle n'est pas présente dans ce dossier. Ses dépendances
  et son fonctionnement ne sont pas couverts par App_vibration.
- `artefacts_python/` : anciens fichiers compilés Python 3.15, précédemment
  suivis dans Git. Conservés comme archives uniquement ; ne pas les utiliser.
  Les nouveaux caches Python sont ignorés par Git.

La version active est à la racine. La branche `v1.2` conserve l'état précédent,
le tag `v1.1` la livraison originale et le commit `30332bb` la V1.0.
L’historique Git n’a pas été réécrit.
