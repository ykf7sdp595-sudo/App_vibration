# Grenier — archives du projet

Ces fichiers sont conservés pour consultation. Ils ne sont ni nécessaires au
lancement d’App_vibration V1.1 ni inclus dans sa suite de tests.

- `documentation/` : notes des étapes 2 à 7, déplacées sans modification.
- `application_rf/test.py` : ancienne application RF indépendante, récupérée
  à l’identique depuis le tag `v1.1`. Elle avait déjà été supprimée de `main`.
  Ses dépendances et son fonctionnement ne sont pas couverts par App_vibration.
- `artefacts_python/` : anciens fichiers compilés Python 3.15, précédemment
  suivis dans Git. Conservés comme archives uniquement ; ne pas les utiliser.
  Les nouveaux caches Python sont ignorés par Git.

La version active est à la racine. Le tag `v1.1` conserve la livraison originale
et le commit `30332bb` conserve V1.0. L’historique Git n’a pas été réécrit.
